# Riot gameplay bots

DevHacks, Riot track 1 (prompt 01): **Gameplay bots: agents that play and adapt.**

## The brief

Explore a new role for AI gameplay bots in Riot's games. Choose a player or
development need and define an experience around it. Decide what the bot should
contribute, how it should adapt, and why someone would use it.

| | |
| --- | --- |
| Who it helps | Players practicing together, and designers exploring bot behavior. |
| Build | The bot, plus a small environment where its decisions can be observed. |
| Show | The bot handling a new situation, and how that helps its user. |
| Demo | bot → scenario → behavior trace |

Keep in mind: a bot's value depends on its role, not just its win rate.

## How it is judged

Use case + original solution + evidence.

- **Not enough:** a bot that moves or wins, or a chain of agents writing code,
  with no real player or developer problem behind it.
- **Strong:** find an unmet need or a costly bottleneck, then invent a new way
  for AI to handle it.
- **Proof:** compare against a simpler bot or workflow. Show verified results
  and the time, effort or errors saved.
